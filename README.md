# Restaurante Fujiyama

Site do Restaurante Fujiyama (Rua Potsdam, 67, São Paulo/SP). Site estático em HTML, CSS e JavaScript puro, sem build.

## Como editar

Quase tudo que muda com frequência fica em `js/dados.js`:

- `contato`: WhatsApp, telefone e Instagram. Campo vazio esconde o botão.
- `horarios`: horários de funcionamento.
- `cardapio`: categorias e pratos. `preco: null` mostra "Consulte".

## Ver localmente

Abra `index.html` no navegador.

## Publicar

Pode ser publicado no GitHub Pages (Settings → Pages → branch principal, pasta raiz), Netlify ou Vercel.
